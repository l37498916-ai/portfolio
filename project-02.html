02 / Interactive Narrative

第零夜 THE ZERO NIGHT

基于 AI 工作流和 Vibe Coding 的沉浸式视觉叙事游戏项目，以循环悬疑、动态档案美学和身份选择交互，构建可进入、可体验、可继续迭代的网页视觉小说原型。

AI 工作流 Vibe Coding 视觉小说 动态档案

Project Positioning

选择身份 进入循环
追踪真相

《第零夜》是一个以“循环悬疑”为核心概念的 AI 辅助智能视觉叙事实验。项目尝试通过交互叙事、动态视觉与沉浸式 UI，构建具有情绪氛围与世界观感的体验原型。

类型
网页视觉小说 / 沉浸式交互原型
职责
AI 工作流组织 / Vibe Coding 整合 / 视觉体验包装
输出
1 个可浏览 HTML 原型 / 1 支动态片头 / 3 组 AIGC 素材池

Background Problem

背景问题

这个项目不是单纯做一组氛围视觉，而是要把悬疑世界观、身份分支、档案界面和可运行原型组织成同一套可进入的叙事体验。

叙事需要被体验

故事信息不能只靠文字说明，而要通过身份入口、界面节奏和线索组织被直接感知。

视觉需要形成系统

角色、场景、道具和档案界面要共享同一世界观气质，而不是零散素材拼贴。

原型需要可演示

最终输出必须是可浏览、可切换、可继续迭代的网页视觉小说原型，而不是静态设定集。

My Role

我的职责

我在项目中主要负责 AI 工作流组织与整体视觉体验整合，包括通过 Vibe Coding 整合组员代码、搭建交互原型，并利用 AIGC 生成项目素材池与动态视觉资源。

UI 氛围设计 身份选择体验 动态片头节奏 AIGC 素材池 HTML / Godot 原型

我在项目中完成了什么

  • AI 工作流组织：拆解叙事关键词，整理并筛选 3 组 AIGC 视觉素材池。
  • Vibe Coding 整合：协助整合组员代码，推进 1 个 HTML 原型与 Godot 尝试版本。
  • 视觉体验整合：统一身份选择、旧档案系统、VHS 加载与页面节奏。
  • 可验证输出：完成 1 支动态片头与 1 个可浏览、可演示的沉浸式视觉小说原型。
